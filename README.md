## 1. Цель и постановка задачи

Цель работы — запрограммировать и экспериментально сравнить алгоритмы, которые используют модель среды для дополнительных виртуальных обновлений Q-функции. Исследование проводится на лабиринте `Maze` со стартом `S`, целью `G`, четырьмя действиями и штрафом за лишние шаги. Для нестационарного эксперимента стены изменяются во времени.

Проверяются два источника улучшения политики: модельное планирование после наблюдаемого перехода и многошаговое обновление с горизонтом `n`.

## 2. Теория

Для наблюдаемого перехода используется TD-обновление:

$$Q(S_t,A_t) \leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\max_aQ(S_{t+1},a)-Q(S_t,A_t)\right].$$

После перехода сохраняется модель $M(S,A)=(R,S')$. Планировщик выбирает известную пару и делает `n` виртуальных обновлений. В Dyna-Q+ к модельной награде добавляется $\kappa\sqrt{\tau}$, где $\tau$ — время с последней проверки перехода. Для n-step SARSA используется возврат:

$$G_{t:t+n}=\sum_{i=1}^{n}\gamma^{i-1}R_{t+i}+\gamma^nQ(S_{t+n},A_{t+n}).$$
